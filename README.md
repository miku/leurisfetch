# leurisfetch
Fetch data from leuris 

    $ make data      # fetch publications.jsonl and projects.jsonl
    $ make report    # write report.html and report.md

The report covers research areas, a timeline, funding, publishing habits,
people and curiosities. Run `leurisreport -h` for options; `-f md` (or an
output file ending in `.md`) writes Markdown instead of HTML.
